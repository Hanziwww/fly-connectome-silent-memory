\subsection{Data and code availability}
\begin{itemize}
  \item This paper analyzes existing, publicly available data, accessible at the DOIs and accession numbers listed in the key
  resources table. The simulation records, trained models and result tables have been deposited at Zenodo as a core record
  (\url{https://doi.org/10.5281/zenodo.23629827}) and an extended record (\url{https://doi.org/10.5281/zenodo.23629835}). The files are under restricted access
  during peer review. Editors and reviewers may obtain access from the lead contact. A manifest lists every deposited file
  with its SHA-256 hash.
  \item All original code is publicly available on GitHub at \url{https://github.com/Hanziwww/fly-connectome-silent-memory}, release v\ident{1.0.0}.
  \item Any additional information required to reanalyze the data reported in this paper is available from the lead contact
  upon request.
\end{itemize}
